## Ce qui fait foi

Chaque équipe devait fournir un article dev.to et une **vidéo de démo** montrant la chaîne complète, du profil aux documents générés. **Un document qui n'est pas produit à l'écran par la solution n'est pas compté.**


## La grille (100 points)

| Bloc | Critère | Points |
| --- | --- | --- |
| ① Socle commun (30) | Créativité & esthétique | 4 |
| | UX & utilisabilité | 5 |
| | Accessibilité | 4 |
| | Adéquation moyens / résultats | 5 |
| | Standards & Open Data (ex. schema.org) | 6 |
| | Storytelling | 4 |
| | Réutilisabilité & essaimage | 4 |
| ② Technicité (25) | Pertinence des ressources | 8 |
| | Intégrabilité (ATS, plateformes d'emploi) | 8 |
| | Maintenabilité | 5 |
| | Interaction inédite (bonus, sans pénalité) | 4 |
| ② Valeur RH (25) | Qualité du matching | 5 |
| | Qualité des documents générés | 5 |
| | Qualité de la restitution | 5 |
| | Facilité de création | 5 |
| | Effet sur la décision | 5 |
| ③ Piste (20) | Qualité de la chaîne de matching (exécution locale en onPrem) | 4 |
| | Architecture, frameworks open source, déployabilité / cohérence des licences, intégrations ou accessibilité du matériel | 2 chacun |

**Deux pistes, une par équipe :**

- **SaaS no limit** : tous les services cloud sont permis
- **onPrem souverain** : les couches de valorisation et d'orchestration tournent sur du matériel physique opéré en Nouvelle-Calédonie (portable, Jetson, DGX Spark, Mac Studio, mini-PC, datacenter local). **L'utilisation de services cloud type [TailCcale](https://tailscale.com/) pour faire communiquer des machines type HomeLab est autorisée.**
