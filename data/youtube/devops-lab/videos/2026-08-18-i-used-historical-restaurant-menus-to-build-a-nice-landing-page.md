Démo réalisée pour le DEV.to Frontend Challenge (Comfort Food Edition), dimanche soir.
Adrien réutilise les données historiques du saga auptitcafe (scraping continu depuis 2023 du restaurant Lumia en Nouvelle-Calédonie) pour construire une landing page GitHub Pages : statistiques de diversité des menus, navigation temporelle dans l'historique, focus desserts, dark/light theme.

- Article Dev.to : https://dev.to/adriens/i-used-historical-restaurant-menus-to-build-a-nice-landing-page-1hfl
- Code source : https://github.com/adriens/auptitcafe-landing
- Site live : https://adriens.github.io/auptitcafe-landing/
- Données historiques : https://github.com/adriens/auptitcafe-data

Nouvelle brique du saga auptitcafe : après le SDK de scraping PyPI, le dataset Kaggle et l'agent chat HuggingFace, une landing page qui met en avant la donnée historique plutôt que la technique front-end pure — générée quasi entièrement par code assistant, mise à jour hebdomadaire via GitHub Action.
